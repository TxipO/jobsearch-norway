## Крок 2 — розбір вакансії

1. Прочитати оголошення повністю.
2. Перевірити, чи вакансія є в `data/jobsearch.db`. Якщо ні — додати через
   `db.upsert_vacancy_row()` + `rescore_all()`.
3. Таблиця відповідності: їхня вимога → його факт.
4. **Ліміт символів з'ясувати ДО написання.**
5. Мова = мова оголошення. Виняток: якщо письмова норвезька сама є
   кваліфікаційною вимогою, яку оцінюють — запропонувати англійську, якщо
   оголошення її дозволяє, і дати користувачу вирішити.

## Крок 4 — прогнати чек-лист скриптом, не очима

```python
import re
s = open('draft.txt', encoding='utf-8').read()
starts = [p.split()[0] for p in s.split('\n\n')]
print('символів:', len(s), '| CRLF:', len(s) + s.count('\n'))
print('довгих тире:', s.count('—'), '(має бути 0)')
print('початки унікальні:', len(starts) == len(set(starts)), starts)
bad = re.findall(r'[^.!?]*(?:не зміг би|не очевидн|слабш|бракує|на жаль|вдавати|'
                 r'ikke kunne|dessverre|mangler|not an obvious|weakest|thinnest)[^.!?]*[.!?]', s)
print('самопринижень:', bad or 'нема')
print('останній змістовний абзац:', s.split('\n\n')[-3][:90])
print('5.5:', re.findall(r'[^.!?]*(?:\bтож\b|\bотже\b|це означає|наскільки я розумію|det betyr at|med andre ord)[^.!?]*[.!?]', s) or 'ok')
print('5.6:', re.findall(r'[^.!?]*(?:з України|в Норвегії|одаюся на|fra Ukraina|søker på stillingen)[^.!?]*[.!?]', s) or 'ok')
print('5.1.4:', re.findall(r'[^.!?]*\bа не\b[^.!?]*[.!?]', s) or 'ok')
```

Плюс вручну:
- [ ] Жодного речення, яке **описує лист** замість того, щоб бути листом.
- [ ] Кожен доказ прив'язаності до компанії — **з життя кандидата, не з їхнього сайту**.
- [ ] **Структуру задає фах кандидата, а не збіг стека** (§5.3).
- [ ] Прогалина названа лише якщо визначає здатність працювати; **одним підрядним, не абзацом**; не в кінці листа.
- [ ] Тривалість роботи над проєктами звірена з `git log --reverse`.
- [ ] **Нічого не стверджувати від імені користувача, чого я не перевірив** (референси, сертифікати, наявність документів).
- [ ] Референси: писати `Referanser oppgis ved forespørsel`, а не перелік і не обіцянку додати контакти.
- [ ] **НЕ писати про походження й статус проживання** (§5.6). «Я з України», «півтора року в Норвегії», «подаюся на позицію X» — прибрати. Питання до кожного речення: воно закриває тему чи запрошує її? Рівні мов (A1/B2) закривають — їх лишати.
- [ ] **Є посилання на репозиторій — не переказувати його зміст прозою** (§5.6).
- [ ] **Кожне число точне, але зайве число не називати** (§5.7). Мала правдива цифра, що працює проти, замінюється на чесне узагальнення, НЕ на більшу цифру.
- [ ] **ШІ-проєкти й GitHub ведуть лише коли предмет вакансії це ШІ/автоматизація.** Support/інфраструктура → хребет це фах. Сумнів → фах.
- [ ] **Форма взята зі схваленого листа → таблицю «вимога → факт» скласти ЗАНОВО** (§5.8). Пройти по кожному місцю роботи окремо: чи є тут факт, якого в зразку не було, бо зразок був про інше?
- [ ] **Досвідний абзац починається з фаху, не з їхніх технологій. Обов'язки як процес, не перелік** (§5.8).
- [ ] **Щойно правив факт у каноні? Grep по вже поданих листах на стару версію** (§5.10), результат — у soknad-log.md.
- [ ] **Перейменована технологія подана як `стара (нова)`** (§5.9): `Active Directory (Entra ID)`. Перший читач часто фільтр за ключовими словами. Дужка НЕ для технології, якої в досвіді не було.
